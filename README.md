# دستیار من 🌱

دستیار شخصی روزانه فارسی‌زبان برای اندروید — با هوش مصنوعی واقعی، ردیابی پریود، پوست،
بی‌رمقی، چک‌این روزانه، ساخت تصویر، آشپزی و کارها.

## 📲 دانلود و نصب

**همیشه آخرین نسخه:** از صفحهٔ [Releases](https://github.com/wizardtcman-design/dastyar-man/releases/latest) وارد شوید و فایل `dastyar-man-release.apk` را در بخش **Assets** دانلود کنید.

> نکته: اگر صفحهٔ Releases نسخهٔ قدیمی نشان می‌دهد، یک‌بار صفحه را **رفرش** کنید
> (Ctrl+F5) یا از حالت ناشناس استفاده کنید؛ نسخهٔ نهایی همیشه با برچسب «Latest» مشخص است.

### نصب روی گوشی
1. فایل APK را دانلود کنید.
2. اگر اندروید اجازه خواست، «نصب از منابع نامشخص» را برای مرورگر یا فایل‌منیجر فعال کنید.
3. نصب کنید. اگر نسخهٔ قبلی نصب است، همان‌جا **آپدیت** می‌شود و اطلاعاتت پاک نمی‌شود.

### چرا آپدیت بدون پاک کردن اطلاعات کار می‌کند؟
همهٔ نسخه‌ها با **یک کلید امضای ثابت** امضا می‌شوند (کلید در Secrets گیت‌هاب نگه‌داری
می‌شود، نه در کد). تا وقتی همین کلید استفاده شود، اندروید نسخهٔ جدید را روی نسخهٔ قبلی
نصب می‌کند و داده‌ها حفظ می‌شوند.

## ✨ ویژگی‌ها
- 💬 گفتگوی هوشمند و مشاورهٔ روزانه (OpenRouter)
- 🩸 ردیابی چرخهٔ پریود و درد
- ✨ وضعیت پوست و روتین ساده
- ⚡ انرژی، خواب، آب، استرس و بی‌رمقی
- 📝 چک‌این روزانهٔ کوتاه + پیشنهاد شخصی‌شده
- 🔔 یادآوری روزانهٔ آفلاین با اعلان
- 🎨 ساخت تصویر با هوش مصنوعی
- 🍳 پیشنهاد غذا با مواد موجود
- ✅ مدیریت کارها با یادآور

## 🔐 حریم خصوصی
همهٔ داده‌های سلامتی فقط روی گوشی شما ذخیره می‌شوند. کلید API در کد نیست. این برنامه
تشخیص پزشکی نمی‌دهد و جایگزین پزشک نیست.

## 🛠 ساخت خودکار
هر push روی شاخهٔ `main` به‌صورت خودکار با GitHub Actions ساخته و در Releases منتشر می‌شود.
